什么是 PostgreSQL？它有哪些特性？
PostgreSQL概述

1. 定义：

PostgreSQL 是流行的对象关系型数据库管理系统（ORDBMS），用于构建高级应用的开源平台。支持多版本并发控制（MVCC）、客户-服务器网络架构、基于日志和触发器的复制、SSL 与高可用备用服务器。

2. 核心特性：

  • 数据完整性：约束体系帮助构建容错环境。
  • 丰富的数据类型：UUID、数组、JSON、几何图元、任意精度数值、XML 等全覆盖。
  • 可扩展：自定义函数（PL/pgSQL、Python、Perl 等多种语言）、GiST 索引框架可扩展任意数据类型。
  • SQL 标准遵循度高，功能丰富（窗口函数、CTE、全文搜索）。

💡 优缺点：可靠、稳定、可扩展、跨平台开源；但简单读场景性能略逊 MySQL，生态应用少一些。

PostgreSQL 的 MVCC 是如何实现的？
MVCC

1. 目的：

用多版本并发控制避免不必要的锁，读不阻塞写、写不阻塞读，消除并发访问的延迟。

2. 机制：

  • 每行（元组）带有 xmin（创建事务 ID）与 xmax（删除事务 ID）系统字段；更新 = 标记旧行失效 + 插入新版本行，旧版本保留在表中供其他事务可见。
  • 事务通过快照判断哪个版本对自己可见。
  • 旧版本由 VACUUM 清理回收（这也是 PG 表膨胀问题的来源，需合理配置 autovacuum）。

💡 与 MySQL InnoDB 的区别：InnoDB 旧版本放 undo log，PG 直接把多版本留在表里，回滚更快但需要 VACUUM。

PostgreSQL 有哪些索引类型？分别适用什么场景？
索引
类型适用场景
B-tree（默认）等值与范围查询，最通用的索引
Hash仅等值比较（=），不支持范围
GiST可扩展框架：几何/空间数据（PostGIS）、范围类型、全文搜索
GIN倒排索引：JSONB、数组、全文检索（ contains 类查询）
BRIN超大表、数据与物理顺序强相关（时序数据），索引极小
SP-GiST空间分区树：点、前缀树等非平衡结构

CREATE INDEX 默认建 B-tree，按查询模式显式指定其他类型可大幅提升性能（如 JSONB 字段查询建 GIN）。

PostgreSQL 的表分区有哪些方式？
分区

1. 定义：

把大表拆成若干小分区，逻辑上是一张表、物理上分散存储，缩小单表规模、便于维护。

2. 支持的分区类型：

  • 范围分区（Range）：按连续区间拆，如按月/按年拆订单表 —— 时序数据最常用。
  • 列表分区（List）：按离散值拆，如按地区、按状态。
  • 哈希分区（Hash）：按 key 哈希均匀打散，无明显业务边界时用。
  • 官方通过表继承实现，需像主表的子表一样创建每个分区；分区键应包含在主键中。

3. 收益：查询可裁剪到相关分区（partition pruning）；单分区损坏只影响局部；历史数据可整体卸载归档。

什么是 WAL（预写日志）？有什么作用？
WAL可靠性

1. 定义：

Write-Ahead Logging：修改数据页之前，先把变更顺序写入事务日志，保证数据完整性的标准方法。

2. 作用：

  • 崩溃恢复：数据库崩溃后重放 WAL，把数据恢复到故障前的已提交状态，工作从中断点继续。
  • 提升写性能：只需顺序写日志即视为提交成功，数据页的随机写可以延迟批量刷盘。
  • 复制基础：流复制把 WAL 传给备库回放，实现主备同步与高可用。

什么是 BRIN 索引？为什么它非常小？
索引进阶

1. 原理：

Block Range Index（块范围索引）：PG 读取每 8KB 数据页块中该列的最小值和最大值，在索引里只保存"页码范围 + min/max"摘要。查询时先通过 BRIN 判断哪些块范围不可能包含目标数据，直接跳过，只扫描候选块。

2. 为什么小：

普通 B-tree 每行都要建索引项，BRIN 每个块范围只存一条摘要 —— 10 亿行的表索引可能只有几十 MB。

3. 适用条件：数据的物理存储顺序与查询列强相关（如按时间顺序插入的时序表），否则 min/max 区间重叠严重、过滤效果差。

Oracle 分区是怎样优化数据库的？
Oracle分区

1. 分区类型：列表分区、范围分区、散列分区、复合分区。

2. 优化收益：

  • 高可用：单分区故障不影响其余分区继续服务；只修复受损分区，缩短停机时间。
  • 易维护：分区独立管理（备份、清理历史数据按分区操作）。
  • 均衡 I/O：不同分区放不同磁盘，分散读写压力。
  • 并行加速：大表的查询与增删改可分解到各分区并行执行。
  • 对用户透明：SQL 无需感知分区存在。

💡 通用优化思路（减少磁盘 I/O）：物理层选好优化器与实例参数、建索引、分区；逻辑层 SQL 用绑定变量复用执行计划、避免 select *、用 exists 替代 in、批量处理。

Oracle 有哪几种文件类型？导入导出有哪些方式？
Oracle

1. 三类文件：

  • 数据文件（.dbf / .ora）：存放实际数据。
  • 日志文件（.log）：重做日志，保证可恢复。
  • 控制文件（.ctl）：记录库的结构信息（文件位置、SCN 等）。

2. 导入导出两种方式：

  • exp/imp 工具：导出二进制转储文件（全库/用户/表级）。
  • PL/SQL 工具：导出 SQL 语句文本（可读、可编辑）。
