SpringBoot 自动配置原理？
SpringBoot高频

1. 定义：

Spring Boot 自动配置是根据项目引入的依赖（classpath 中的类）以及配置文件中的属性，自动判断并加载合适的 Spring 配置类和 Bean，从而大大减少开发者手动编写 XML 或 Java 配置的工作量。

2. 作用：

  • 简化配置：

    无需手动编写大量 @Configuration 和 @Bean。
  • 按需装配：

    只加载项目实际需要的配置，避免冗余。
  • 约定优于配置：

    提供合理的默认行为，同时允许用户自定义覆盖。
  • 开箱即用：

    引入依赖后即可使用，例如引入 spring-boot-starter-web 就自动配置 Spring MVC。

3. 原理：

  1. 入口注解：

    @SpringBootApplication 包含 @EnableAutoConfiguration，通过 @Import(AutoConfigurationImportSelector.class) 导入选择器。
  2. SPI 机制：

    扫描所有依赖 JAR 包中的 META-INF/spring.factories（Spring Boot 2.7+ 使用 META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports），收集候选自动配置类。
  3. 条件过滤：

    通过 @ConditionalOnClass、@ConditionalOnMissingBean、@ConditionalOnProperty 等条件注解，按项目实际情况筛选出需要生效的配置类。
  4. Bean 注册：

    将符合条件的配置类中的 @Bean 注册到 Spring 容器。
  5. 用户自定义优先：

    如果用户自己定义了某个 Bean，自动配置的 Bean 将不会生效，体现"约定优于配置，但配置可覆盖约定"。

💡 自定义 Starter：

创建 autoconfigure 模块 → 编写配置类 → 在 imports 文件中注册。

SpringBoot 启动流程？
SpringBoot源码
  1. 创建SpringApplication实例。
  2. 获取SpringApplicationRunListeners，发布starting事件。
  3. 准备Environment（加载配置文件）。
  4. 创建ApplicationContext(IOC容器)。
  5. 准备Context（设置environment、注册组件、执行初始化器）。
  6. 刷新Context（Bean的创建和初始化，Tomcat启动等）。
  7. 发布started/ready事件。
  8. 回调ApplicationRunner和CommandLineRunner。

@SpringBootApplication 注解包含哪些注解？
SpringBoot

@SpringBootApplication是复合注解，包含：

  • @SpringBootConfiguration：

    标识为配置类（含@Configuration）。
  • @EnableAutoConfiguration：

    自动配置核心。
  • @ComponentScan：

    组件扫描（扫描启动类所在包及子包下的@Component等）。

这3个注解的组合封装，简化了Spring Boot应用的启动配置。

Spring Boot 如何实现优雅停机？
SpringBoot运维

Spring Boot 2.3+支持优雅停机：

  • server.shutdown=graceful
  • spring.lifecycle.timeout-per-shutdown-phase=30s

原理：

  • 收到SIGTERM→不再接受新请求→等待现有请求处理完→关闭容器。
  • 配合K8s的preStop hook，实现滚动更新不丢流量。
  • Spring Boot Actuator的/actuator/shutdown端点也可管理。
