SpringBoot 自动配置原理？
SpringBoot高频

核心注解：@SpringBootApplication @EnableAutoConfiguration @Import(AutoConfigurationImportSelector)

  1. 启动类@SpringBootApplication。
  2. @EnableAutoConfiguration通过AutoConfigurationImportSelector加载自动配置类。
  3. 读取META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports(SpringBoot 2.7+)或spring.factories。
  4. 根据@Conditional条件注解判断是否生效(如@ConditionalOnClass)。

SpringBoot 启动流程？
SpringBoot源码
  1. 创建SpringApplication实例。
  2. 获取SpringApplicationRunListeners，发布starting事件。
  3. 准备Environment（加载配置文件）。
  4. 创建ApplicationContext(IOC容器)。
  5. 准备Context（设置environment、注册组件、执行初始化器）。
  6. 刷新Context（Bean的创建和初始化，Tomcat启动等）。
  7. 发布started/ready事件。
  8. 回调ApplicationRunner和CommandLineRunner。

Spring Boot 自动配置原理？
SpringBoot高频

核心注解@SpringBootApplication包含三个关键注解：

  1. @EnableAutoConfiguration：通过@Import(AutoConfigurationImportSelector.class)加载META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports（Spring Boot 2.7+）或spring.factories中的配置类。
  2. 根据@Conditional系列注解（如@ConditionalOnClass、@ConditionalOnMissingBean）决定是否生效。

💡 自定义Starter：创建autoconfigure模块→编写配置类→在imports文件中注册。

@SpringBootApplication 注解包含哪些注解？
SpringBoot

@SpringBootApplication是复合注解，包含：

  • @SpringBootConfiguration：标识为配置类（含@Configuration）。
  • @EnableAutoConfiguration：自动配置核心。
  • @ComponentScan：组件扫描（扫描启动类所在包及子包下的@Component等）。

这3个注解的组合封装，简化了Spring Boot应用的启动配置。

Spring Boot 如何实现优雅停机？
SpringBoot运维

Spring Boot 2.3+支持优雅停机：

  • server.shutdown=graceful
  • spring.lifecycle.timeout-per-shutdown-phase=30s

原理：

  • 收到SIGTERM→不再接受新请求→等待现有请求处理完→关闭容器。
  • 配合K8s的preStop hook，实现滚动更新不丢流量。
  • Spring Boot Actuator的/actuator/shutdown端点也可管理。
