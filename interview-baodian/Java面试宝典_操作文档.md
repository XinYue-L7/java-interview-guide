## 第一章 项目概述

### 1.1 项目简介

Java面试宝典是一套纯静态HTML面试刷题系统，覆盖Java工程师面试的 **8大核心板块**，共约 **300道面试题**，支持本机浏览与局域网多端共享访问。

项目以零依赖纯前端方式运行，仅需一个HTTP服务器即可提供局域网内任何设备访问，适合面试突击、每日刷题、团队共享等场景。

│  电脑浏览器  │  手机浏览器  │  平板浏览器      │

│  总目录页面     │  生成二维码.py 构建工具       │

## 第三章 操作使用

### 3.1 环境准备

- Python 3.6+（用于启动HTTP服务器和运行构建脚本）
- 安装依赖：`pip install qrcode pillow`（仅二维码功能需要）
- 任何现代浏览器（Chrome / Edge / Firefox / Safari）

### 3.2 启动服务

```powershell
cd D:\AiWordSpace
    python -m http.server 9876
```

| 参数 | 说明 |
|------|------|
| `9876` | 端口号，可改为 8080 / 8888 等 |
| `--bind 0.0.0.0` | （可选）绑定所有网卡，允许局域网访问 |

### 3.3 本机访问

浏览器打开：

- `http://localhost:9876/Java面试宝典_总目录.html`

总目录页面提供三个维度入口：

- **分类浏览** — 8大板块卡片入口
- **全局搜索** — 输入关键词快速定位
- **高频题筛选** — 只看 ⭐ 标记的103道高频题

### 3.4 构建搜索索引

如果对题目内容有增删改，需重建索引：

```powershell
python build_search_index.py
```

该脚本扫描所有 `Java面试宝典_0*.html` 文件，提取每题标题和标签，输出 `search_index.json`。

### 3.5 批量更新模块页面

当需要统一修改所有模块页面的公共部分（导航/页脚/样式）时：

```powershell
python batch_update_modules.py
```

## 第四章 多端访问与二维码

### 4.1 方案概述

Java面试宝典支持同一WiFi下的**多设备同步访问**。核心技术链路：

```
手机/平板 ──扫码──▶ qrcode_lan.png ──跳转──▶ http://{局域网IP}:9876/Java面试宝典_总目录.html
```

整套方案由3个文件协同完成：

| 文件 | 作用 |
|------|------|
| `生成二维码.py` | 自动获取本机IP，生成最新二维码图片 |
| `qrcode_lan.png` | 二维码图片文件（838B），编码局域网访问地址 |
| `扫码访问.html` | 精美的扫码入口页面，展示二维码+复制链接功能 |

### 4.2 生成二维码

每次切换网络后，需要重新运行以下命令更新二维码：

```powershell
python 生成二维码.py
```

**脚本逻辑：**

| 步骤 | 说明 | 关键代码 |
|------|------|----------|
| ① 获取局域网IP | 通过UDP连接 8.8.8.8 自动获取本机活跃IP | `socket.connect(('8.8.8.8', 80))` |
| ② 拼接URL | 使用固定端口 9876 拼接完整访问地址 | `http://{IP}:9876/Java面试宝典_总目录.html` |
| ③ 生成二维码 | 使用 qrcode 库生成PNG图片 | `qrcode.make(url).save('qrcode_lan.png')` |
| ④ 输出结果 | 控制台打印二维码路径和访问URL | `print('二维码已生成...')` |

**完整脚本源码：**

```python
import qrcode
import socket

def get_lan_ip():
    s = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
    try:
        s.connect(("8.8.8.8", 80))
        ip = s.getsockname()[0]
    except Exception:
        ip = "127.0.0.1"
    finally:
        s.close()
    return ip

ip = get_lan_ip()
port = 9876
url = f"http://{ip}:{port}/Java面试宝典_总目录.html"
img = qrcode.make(url)
img.save("qrcode_lan.png")
print(f"二维码已生成: qrcode_lan.png")
print(f"访问地址: {url}")
```

### 4.3 扫码访问页面

`扫码访问.html` 是一个独立的精美页面，核心功能：

- 展示 `qrcode_lan.png` 二维码，手机相机扫码即可跳转
- 显示完整访问 URL，方便手动输入
- 「复制链接」按钮，一键复制到剪贴板
- 提示信息：手机和电脑需连接同一WiFi
- 电脑端快捷跳转链接

**当前硬编码的链接：**

```javascript
const lanUrl = 'http://192.168.5.171:9876/Java面试宝典_总目录.html';
```

> ⚠️ 注意：该 IP 为首次生成时的局域网地址，**切换网络后需重新运行 `python 生成二维码.py` 更新**。

### 4.4 分享链接汇总

| 使用场景 | 链接地址 | 说明 |
|----------|----------|------|
| 本机访问 | `http://localhost:9876/Java面试宝典_总目录.html` | 电脑自己打开 |
| 局域网访问 | `http://{本机IP}:9876/Java面试宝典_总目录.html` | 同WiFi下其他设备 |
| 二维码编码 | 同上（局域网地址） | 扫码即可跳转 |
| 扫码入口 | `http://{本机IP}:9876/扫码访问.html` | 进入扫码页面 |

### 4.5 多端使用完整流程

1. **步骤1**：电脑启动 HTTP 服务器
   ```powershell
   cd D:\AiWordSpace
   python -m http.server 9876
   ```

2. **步骤2**：管理员身份执行防火墙放行命令（仅首次需要）
   ```powershell
   New-NetFirewallRule -DisplayName "Python HTTP Server 9876" -Direction Inbound -Protocol TCP -LocalPort 9876 -Action Allow
   ```

3. **步骤3**：运行 `python 生成二维码.py` 生成最新二维码

4. **步骤4**：手机/平板打开相机，扫描 `qrcode_lan.png`

5. **步骤5**：或手动在手机浏览器输入 `http://{电脑IP}:9876/Java面试宝典_总目录.html`

6. **步骤6**：开始刷题！手机端自动适配响应式布局

**防火墙放行流程图：**

```
电脑启动服务器 → 手机访问 http://IP:9876 → 若无法访问 → 检查防火墙
├─ 已放行端口 → 检查是否同一WiFi
└─ 未放行 → 管理员PowerShell执行放行命令
```

## 第五章 功能说明

### 5.1 主题切换

每个模块页面顶部右侧提供「主题」下拉菜单，共5套配色方案：

| 主题名称 | 配色特点 | 适用场景 |
|----------|----------|----------|
| 深绿护眼 | 深色底+绿色强调 | 长时间刷题 |
| 黑白金简约 | 白色底+金色点缀 | 正式面试场景 |
| 紫色优雅 | 紫色渐变+白色卡片 | 喜欢暗色风格 |
| 浅色清爽 | 浅灰底+蓝色链接 | 白天阅读 |
| 深色极简 | 纯黑底+白色文字 | 夜间模式 |

主题选择存储在 `localStorage` 中，刷新页面后仍然生效。

### 5.2 答案折叠/展开

- 每题答案默认折叠，点击题目标题展开/收起
- 模块顶部提供「全部展开」「全部折叠」快捷按钮
- 展开状态支持平滑过渡动画
- 高频题（⭐标记）标题左侧有醒目标识

### 5.3 全局搜索

三级搜索策略，在总目录页顶部搜索框使用：

| 搜索层级 | 匹配范围 | 示例 |
|----------|----------|------|
| ① 标题匹配 | 题目标题全文搜索 | 输入「HashMap」→ 匹配所有HashMap相关题目 |
| ② 标签匹配 | 标签精确/模糊匹配 | 输入「线程」→ 匹配标签含「多线程」的题 |
| ③ 模块匹配 | 模块名称搜索 | 输入「MySQL」→ 匹配MySQL模块所有题 |

搜索结果直接展示题目编号、标题、所属模块，点击跳转到对应页面。

### 5.4 题目反馈

每题答案下方提供「有帮助」「需要改进」反馈按钮，反馈数据存储在 `localStorage` 中。

### 5.5 导航系统

- 每个模块页面顶部有横向导航条，列出全部8个板块+总目录链接
- 当前所在模块高亮显示
- 总目录页面提供卡片式模块入口

### 5.6 返回顶部

页面右下角固定「↑」返回顶部按钮，滚动超过 200px 后自动显示。

### 5.7 搜索历史

总目录页的搜索框会自动记录最近的搜索关键词（最多20条），存储在 `localStorage`，点击历史记录可快速重新搜索。

## 附录 · 常见问题排查

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 搜索无结果 | search_index.json 未生成或过期 | 运行 `python build_search_index.py` 重建索引 |
| 手机扫码后无法访问 | 防火墙拦截 / 不在同一WiFi / IP变化 | ① 检查防火墙放行 9876 端口 ② 确认手机连了同一WiFi ③ 重新运行 `python 生成二维码.py` |
| 样式错乱 / 主题失效 | localStorage 缓存数据损坏 | 清除浏览器 localStorage 或使用无痕模式 |
| 端口 9876 已被占用 | 其他程序占用了该端口 | 换一个端口：`python -m http.server 8080` |
| 二维码图片显示旧IP | 网络切换后IP已变化 | 重新运行 `python 生成二维码.py` |
| 图片加载失败 | qrcode_lan.png 不存在 | 运行 `python 生成二维码.py` 生成 |
| Python 服务器无法启动 | Python 未安装或环境变量问题 | 检查：`python --version` |
